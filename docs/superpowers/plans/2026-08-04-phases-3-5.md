> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre visibles et vérifiables les résultats du solveur — comparer les
heuristiques, ajouter IDA\* pour survivre au 15-puzzle là où A\* meurt en
mémoire, et publier README, tableaux, graphes et rétrospective tirés des CSV.

deux scripts et jamais écrits à la main.

uniquement, bash.

Dans `src/search.c`, juste avant la section « Point d'entrée », insérer :

```c
/* ------------------------------------------------------------------ */
/* Implementation IDA* : approfondissement iteratif sur f = g + h       */
/*                                                                      */
/* Pas de table d'etats visites, volontairement. C'est elle qui rendrait */
/* la memoire en O(b^d) et ferait perdre tout l'interet de l'algorithme. */
/* La seule elimination est l'anti-retour immediat : ne pas defaire le   */
/* coup qu'on vient de jouer. Un meme etat peut donc etre revisite par   */
/* deux chemins differents, et chaque iteration rejoue tout ce que la    */
/* precedente avait deja explore. Ce qu'on paie en temps (mesure par     */
/* generated / last_iter_generated) on le gagne en memoire : la pile     */
/* d'appel et le tableau de coups, rien d'autre.                        */
/* ------------------------------------------------------------------ */

#define IDA_MAX_DEPTH 128
#define IDA_INF       0x3fffffff

typedef struct {
  const search_opts *o;
  stats_t           *st;
  cell_t             board[MAX_BOARD];
  int                moves[IDA_MAX_DEPTH];
  uintptr_t          stack_base;   /* adresse d'un local a la racine */
  size_t             stack_used;   /* pic reellement mesure */
  int                aborted;
} ida_ctx;

/* Mesure de la pile : on compare l'adresse d'un local a celle prise a la
   racine. La difference est prise en valeur absolue, pour ne rien supposer
   du sens de croissance de la pile. */
static void ida_note_stack(ida_ctx *c, const void *here)
{
  uintptr_t p = (uintptr_t)here;
  size_t    used = (c->stack_base > p) ? (size_t)(c->stack_base - p)
                                       : (size_t)(p - c->stack_base);
  if (used > c->stack_used) c->stack_used = used;
}

/*
 * Rend -1 si le but a ete atteint (la pile de coups c->moves[0..g-1] est alors
 * la solution), sinon le plus petit f rencontre qui depasse `bound` — c'est le
 * seuil de l'iteration suivante.
 */
static int ida_dfs(ida_ctx *c, int blank, int g, int h, int bound, int prev_move)
{
  int probe;                 /* sert uniquement de repere de pile */
  int f = g + h;
  int min_next = IDA_INF;
  int move;

  ida_note_stack(c, &probe);

  if (f > bound) return f;
  if (puzzle_is_goal(c->board)) return -1;
  if (g >= IDA_MAX_DEPTH - 1) return IDA_INF;

  c->st->expanded++;
  if (g > c->st->max_depth) c->st->max_depth = g;

  for (move = 0; move < MAX_MOVES; move++) {
    int nb, hc, t;

    if (prev_move >= 0 && move == puzzle_opposite(prev_move)) continue;

    nb = puzzle_apply(c->board, blank, move, c->board);   /* mutation en place */
    if (nb < 0) continue;

    c->st->generated++;
    c->st->last_iter_generated++;
    c->moves[g] = move;

    if (c->o->max_nodes > 0 && c->st->generated >= c->o->max_nodes) {
      c->aborted = 1;
      puzzle_apply(c->board, nb, puzzle_opposite(move), c->board);
      return IDA_INF;
    }

    hc = heuristic_eval(c->o->heuristic, c->board);
    t  = ida_dfs(c, nb, g + 1, hc, bound, move);

    if (t == -1) return -1;    /* trouve : on garde la pile de coups intacte */

    puzzle_apply(c->board, nb, puzzle_opposite(move), c->board);  /* defaire */

    if (c->aborted) return IDA_INF;
    if (t < min_next) min_next = t;
  }

  return min_next;
}

static int solve_ida(const search_opts *o, const cell_t *start, stats_t *st,
                     int *path, int cap, int *plen)
{
  int       probe;
  ida_ctx   c;
  int       bound, blank, i;

  memset(&c, 0, sizeof(c));
  c.o  = o;
  c.st = st;
  c.stack_base = (uintptr_t)&probe;
  memcpy(c.board, start, MAX_BOARD);

  blank = puzzle_blank(start);
  bound = heuristic_eval(o->heuristic, start);

  for (;;) {
    int t;

    st->last_iter_generated = 0;
    st->iterations++;

    t = ida_dfs(&c, blank, 0, heuristic_eval(o->heuristic, c.board),
                bound, -1);

    if (c.aborted) {
      st->aborted = 1;
      st->bytes_peak = c.stack_used + sizeof(c);
      return SEARCH_ABORTED;
    }

    if (t == -1) {
      *plen = st->max_depth_solution;
      break;
    }

    if (t >= IDA_INF) {                 /* rien au-dela : pas de solution */
      st->bytes_peak = c.stack_used + sizeof(c);
      return SEARCH_NOSOL;
    }

    bound = t;                          /* le seuil suivant est ce minimum */
  }

  /* La solution est la pile de coups. Sa longueur est le nombre de coups
     empiles jusqu'au but, que ida_dfs a laisse en place en remontant. */
  *plen = c.st->solution_depth;
  for (i = 0; i < *plen && i < cap; i++)
    if (path) path[i] = c.moves[i];

  st->solution_len = *plen;
  st->closed_size  = 0;                 /* IDA* ne garde aucun etat ferme */
  st->open_max     = st->max_depth + 1; /* la pile est sa seule « open list » */
  st->bytes_peak   = c.stack_used + sizeof(c);
  return SEARCH_OK;
}
```

### Task 3 : `--enumerate` et `--dist` — le générateur est-il uniforme ?

**Files:**
- Create: `src/enumerate.h`, `src/enumerate.c`
- Create: `tests/test_enumerate.c`
- Modify: `src/taquin.c` (options `--enumerate`, `--dist N`)
- Modify: `Makefile`

**Interfaces:**
- Consumes: `puzzle_goal`, `puzzle_apply`, `puzzle_blank`, `rng_t`.
- Produces:
  - `long perm_rank(const cell_t *b)` — rang de Lehmer dans `[0, 9![`
  - `unsigned char *enum_depths(long *n_solvable, int *max_depth)` — tableau de
    9! octets, `0xFF` pour les états inatteignables, la profondeur optimale
    sinon. À libérer par l'appelant.
  - `void enum_report(void)` — imprime la distribution exacte des profondeurs.
  - `void enum_generator_test(long samples, int shuffle, uint64_t seed)` —
    tire `samples` plateaux, compare deux distributions à leur loi théorique
    par un khi-deux, imprime le verdict.

**Le point de fond.** Un marcheur aléatoire sans retour immédiat sur le graphe
du taquin ne converge **pas** vers la loi uniforme sur les états : sa loi
stationnaire est proportionnelle au degré du sommet. Le degré ne dépend que de
la position de la case vide : 2 aux quatre coins, 3 sur les quatre bords, 4 au
centre, soit une somme de 4×2 + 4×3 + 1×4 = 24. Comme chacune des 9 positions
porte exactement 181 440 / 9 = 20 160 états solvables, la prédiction est :

| position de la case vide | loi uniforme | loi prédite (∝ degré) |
|---|---|---|
| coin (×4) | 11,11 % | 2/24 = **8,33 %** |
| bord (×4) | 11,11 % | 3/24 = **12,50 %** |
| centre (×1) | 11,11 % | 4/24 = **16,67 %** |

C'est un écart énorme et trivialement mesurable. `--dist` doit tester les deux
hypothèses et montrer laquelle le générateur suit.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <math.h>
#include "enumerate.h"

#if WH_BOARD == 3

#define NPERM  362880L        /* 9! */

static const long FACT[10] = { 1,1,2,6,24,120,720,5040,40320,362880 };

long perm_rank(const cell_t *b)
{
  long rank = 0;
  int  i, j;

  for (i = 0; i < MAX_BOARD; i++) {
    int smaller = 0;
    for (j = i + 1; j < MAX_BOARD; j++)
      if (b[j] < b[i]) smaller++;
    rank += (long)smaller * FACT[MAX_BOARD - 1 - i];
  }
  return rank;
}

unsigned char *enum_depths(long *n_solvable, int *max_depth)
{
  unsigned char *depth = malloc(NPERM);
  cell_t        *queue = malloc((size_t)NPERM / 2 * MAX_BOARD);
  long           head = 0, tail = 0, count = 0;
  int            maxd = 0;
  cell_t         goal[MAX_BOARD];

  if (!depth || !queue) { free(depth); free(queue); return NULL; }
  memset(depth, 0xFF, NPERM);

  puzzle_goal(goal);
  depth[perm_rank(goal)] = 0;
  memcpy(queue, goal, MAX_BOARD);
  tail = 1;
  count = 1;

  while (head < tail) {
    cell_t cur[MAX_BOARD], next[MAX_BOARD];
    int    blank, move, d;

    memcpy(cur, queue + head * MAX_BOARD, MAX_BOARD);
    head++;
    d = depth[perm_rank(cur)];
    blank = puzzle_blank(cur);

    for (move = 0; move < MAX_MOVES; move++) {
      long r;
      if (puzzle_apply(cur, blank, move, next) < 0) continue;
      r = perm_rank(next);
      if (depth[r] != 0xFF) continue;
      depth[r] = (unsigned char)(d + 1);
      if (d + 1 > maxd) maxd = d + 1;
      memcpy(queue + tail * MAX_BOARD, next, MAX_BOARD);
      tail++;
      count++;
    }
  }

  free(queue);
  if (n_solvable) *n_solvable = count;
  if (max_depth)  *max_depth  = maxd;
  return depth;
}

void enum_report(void)
{
  unsigned char *d;
  long  n = 0, hist[64] = { 0 }, i;
  int   maxd = 0, k;

  d = enum_depths(&n, &maxd);
  if (!d) { printf("memoire insuffisante\n"); return; }

  for (i = 0; i < NPERM; i++)
    if (d[i] != 0xFF) hist[d[i]]++;

  printf("Enumeration exhaustive du 8-puzzle\n");
  printf("  etats solvables    : %ld  (9!/2 = 181440)\n", n);
  printf("  profondeur maximale: %d coups\n", maxd);
  printf("\n  profondeur   etats     part\n");
  for (k = 0; k <= maxd; k++)
    printf("  %10d  %8ld  %6.3f %%\n", k, hist[k],
           100.0 * (double)hist[k] / (double)n);

  free(d);
}

/* Degre d'un sommet = nombre de coups legaux, fonction de la case vide seule. */
static int degree_of_blank(int blank)
{
  int move, n = 0;
  cell_t dummy[MAX_BOARD], out[MAX_BOARD];

  puzzle_goal(dummy);
  for (move = 0; move < MAX_MOVES; move++)
    if (puzzle_apply(dummy, blank, move, out) >= 0) n++;
  return n;
}

/*
 * Khi-deux d'ajustement. Rend la statistique, remplit *df.
 * Les classes d'effectif theorique < 5 sont fusionnees avec la precedente,
 * regle usuelle sans laquelle l'approximation ne tient pas.
 */
static double chi2_fit(const long *obs, const double *expected, int n, int *df)
{
  double chi2 = 0.0, o = 0.0, e = 0.0;
  int    i, bins = 0;

  for (i = 0; i < n; i++) {
    o += (double)obs[i];
    e += expected[i];
    if (e >= 5.0) {
      chi2 += (o - e) * (o - e) / e;
      bins++;
      o = e = 0.0;
    }
  }
  if (e > 0.0) {            /* reste : on le fusionne avec la derniere classe */
    chi2 += (o - e) * (o - e) / e;
    bins++;
  }
  *df = bins > 1 ? bins - 1 : 1;
  return chi2;
}

/*
 * p-valeur du khi-deux par l'approximation de Wilson-Hilferty : (X/k)^(1/3)
 * est approximativement normale de moyenne 1 - 2/(9k) et de variance 2/(9k).
 * Evite d'embarquer une table de quantiles.
 */
static double chi2_pvalue(double chi2, int df)
{
  double k = (double)df;
  double z = (pow(chi2 / k, 1.0 / 3.0) - (1.0 - 2.0 / (9.0 * k)))
             / sqrt(2.0 / (9.0 * k));
  return 0.5 * erfc(z / sqrt(2.0));
}

void enum_generator_test(long samples, int shuffle, uint64_t seed)
{
  unsigned char *d;
  long   n = 0, i;
  int    maxd = 0, k, df;
  long   exact_hist[64] = { 0 }, obs_depth[64] = { 0 };
  long   obs_blank[MAX_BOARD] = { 0 };
  double exp_depth[64], exp_blank_unif[MAX_BOARD], exp_blank_deg[MAX_BOARD];
  double chi2, p, degsum = 0.0;
  rng_t  rng;
  cell_t b[MAX_BOARD];

  d = enum_depths(&n, &maxd);
  if (!d) { printf("memoire insuffisante\n"); return; }

  for (i = 0; i < NPERM; i++)
    if (d[i] != 0xFF) exact_hist[d[i]]++;

  rng_seed(&rng, seed);
  for (i = 0; i < samples; i++) {
    puzzle_goal(b);
    puzzle_shuffle(b, shuffle, &rng);
    obs_depth[d[perm_rank(b)]]++;
    obs_blank[puzzle_blank(b)]++;
  }

  printf("Generateur : %ld tirages de %d coups depuis le but (graine %llu)\n\n",
         samples, shuffle, (unsigned long long)seed);

  /* --- Test 1 : la distribution des profondeurs optimales --- */
  for (k = 0; k < 64; k++)
    exp_depth[k] = (double)samples * (double)exact_hist[k] / (double)n;
  chi2 = chi2_fit(obs_depth, exp_depth, 64, &df);
  p = chi2_pvalue(chi2, df);
  printf("Profondeur optimale, contre la distribution exacte\n");
  printf("  khi-deux = %.1f   ddl = %d   p = %.2e   -> %s\n\n",
         chi2, df, p,
         p < 0.01 ? "ECART SIGNIFICATIF" : "compatible");

  /* --- Test 2 : la position de la case vide --- */
  for (k = 0; k < MAX_BOARD; k++) degsum += (double)degree_of_blank(k);
  for (k = 0; k < MAX_BOARD; k++) {
    exp_blank_unif[k] = (double)samples / (double)MAX_BOARD;
    exp_blank_deg[k]  = (double)samples * (double)degree_of_blank(k) / degsum;
  }

  printf("Position de la case vide\n");
  printf("  case  degre   observe    uniforme   proportionnel au degre\n");
  for (k = 0; k < MAX_BOARD; k++)
    printf("  %4d  %5d  %8.3f %%  %8.3f %%  %8.3f %%\n",
           k, degree_of_blank(k),
           100.0 * (double)obs_blank[k] / (double)samples,
           100.0 * exp_blank_unif[k] / (double)samples,
           100.0 * exp_blank_deg[k] / (double)samples);

  chi2 = chi2_fit(obs_blank, exp_blank_unif, MAX_BOARD, &df);
  p = chi2_pvalue(chi2, df);
  printf("\n  contre la loi uniforme            : khi-deux = %.1f  ddl = %d"
         "  p = %.2e  -> %s\n", chi2, df, p,
         p < 0.01 ? "REJETEE" : "compatible");

  chi2 = chi2_fit(obs_blank, exp_blank_deg, MAX_BOARD, &df);
  p = chi2_pvalue(chi2, df);
  printf("  contre la loi proportionnelle au degre : khi-deux = %.1f  ddl = %d"
         "  p = %.2e  -> %s\n", chi2, df, p,
         p < 0.01 ? "REJETEE" : "compatible");

  free(d);
}

#else /* WH_BOARD != 3 */

long perm_rank(const cell_t *b) { (void)b; return -1; }

}

}

#endif

def svg_plot(path, series, title, xlabel, ylabel, logy=True,
             width=760, height=420):
    """
    series : [(nom, [(x, y), ...]), ...]
    Ecrit un SVG autonome : axes, grille, legende, echelle log optionnelle en y.
    """
    pad_l, pad_r, pad_t, pad_b = 70, 170, 44, 52
    xs = [x for _, pts in series for x, _ in pts]
    ys = [y for _, pts in series for _, y in pts if y > 0]
    if not xs or not ys:
        raise SystemExit(f"serie vide pour {path}")
    x0, x1 = min(xs), max(xs)
    if logy:
        y0, y1 = math.log10(min(ys)), math.log10(max(ys))
    else:
        y0, y1 = 0.0, max(ys)
    if x1 == x0:
        x1 = x0 + 1
    if y1 == y0:
        y1 = y0 + 1

    def px(x):
        return pad_l + (x - x0) / (x1 - x0) * (width - pad_l - pad_r)

    def py(y):
        v = math.log10(y) if logy else y
        return height - pad_b - (v - y0) / (y1 - y0) * (height - pad_t - pad_b)

    p = []
    p.append(f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 {width} {height}" '
             f'width="{width}" height="{height}" font-family="system-ui,sans-serif">')
    p.append('<style>'
             '.bg{fill:#ffffff}.fg{fill:#1f2937}.gr{stroke:#d1d5db}'
             '@media (prefers-color-scheme:dark){'
             '.bg{fill:#0b0f19}.fg{fill:#e5e7eb}.gr{stroke:#374151}}'
             '</style>')
    p.append(f'<rect class="bg" width="{width}" height="{height}"/>')
    p.append(f'<text class="fg" x="{width/2:.0f}" y="24" text-anchor="middle" '
             f'font-size="15" font-weight="600">{title}</text>')

    # grille + graduations y
    ticks = 6
    for i in range(ticks + 1):
        v = y0 + (y1 - y0) * i / ticks
        y = height - pad_b - (v - y0) / (y1 - y0) * (height - pad_t - pad_b)
        p.append(f'<line class="gr" x1="{pad_l}" y1="{y:.1f}" '
                 f'x2="{width-pad_r}" y2="{y:.1f}" stroke-width="1"/>')
        lab = fmt_si(10 ** v) if logy else fmt_si(v)
        p.append(f'<text class="fg" x="{pad_l-8}" y="{y+4:.1f}" '
                 f'text-anchor="end" font-size="11">{lab}</text>')

    # graduations x
    for i in range(6):
        v = x0 + (x1 - x0) * i / 5
        p.append(f'<text class="fg" x="{px(v):.1f}" y="{height-pad_b+18:.0f}" '
                 f'text-anchor="middle" font-size="11">{v:.0f}</text>')

    p.append(f'<text class="fg" x="{(pad_l+width-pad_r)/2:.0f}" y="{height-12}" '
             f'text-anchor="middle" font-size="12">{xlabel}</text>')
    p.append(f'<text class="fg" x="16" y="{height/2:.0f}" font-size="12" '
             f'transform="rotate(-90 16 {height/2:.0f})" '
             f'text-anchor="middle">{ylabel}</text>')

    for i, (name, pts) in enumerate(series):
        c = COLORS[i % len(COLORS)]
        pts = sorted(pts)
        d = " ".join(f'{"M" if j == 0 else "L"}{px(x):.1f},{py(y):.1f}'
                     for j, (x, y) in enumerate(pts) if y > 0)
        p.append(f'<path d="{d}" fill="none" stroke="{c}" stroke-width="2.2"/>')
        for x, y in pts:
            if y > 0:
                p.append(f'<circle cx="{px(x):.1f}" cy="{py(y):.1f}" r="3" fill="{c}"/>')
        ly = pad_t + 6 + i * 20
        p.append(f'<line x1="{width-pad_r+12}" y1="{ly}" x2="{width-pad_r+34}" '
                 f'y2="{ly}" stroke="{c}" stroke-width="2.2"/>')
        p.append(f'<text class="fg" x="{width-pad_r+40}" y="{ly+4}" '
                 f'font-size="12">{name}</text>')

    p.append("</svg>")
    os.makedirs(os.path.dirname(path), exist_ok=True)
    with open(path, "w") as f:
        f.write("\n".join(p) + "\n")
    print("ecrit", os.path.relpath(path, ROOT))


def fmt_si(v):
    for lim, suf in ((1e9, "G"), (1e6, "M"), (1e3, "k")):
        if abs(v) >= lim:
            return f"{v/lim:.1f}{suf}"
    return f"{v:.0f}" if abs(v) >= 1 else f"{v:.2g}"

1. **Admissible et consistante.** Admissible : `h(n) <= h*(n)` pour tout `n`.
   Consistante : `h(n) <= c(n,n') + h(n')` pour tout successeur. Manhattan est
   admissible parce que chaque tuile doit parcourir au moins sa distance de
   Manhattan et qu'un coup ne déplace qu'une tuile d'une case ; elle est
   consistante parce qu'un coup change la somme d'exactement ±1, or `c = 1`.
   C'est la **consistance**, pas l'admissibilité, qui autorise à écarter
   définitivement un nœud déjà fermé : elle garantit qu'un nœud extrait a déjà
   son `g` optimal. Avec une heuristique seulement admissible, il faudrait
   pouvoir rouvrir un nœud fermé. Mesuré : `tests/test_heuristic.c` vérifie
   `h(n) <= 1 + h(fils)` sur 30 000 plateaux et les quatre heuristiques.
2. **Le `+2` du conflit linéaire.** Deux tuiles dans leur ligne but mais
   inversées : l'une doit sortir de la ligne puis y revenir, soit deux coups
   que Manhattan ne compte pas, puisqu'ils s'annulent en distance. La borne
   reste donc inférieure au coût réel. Le piège est le triplet : trois tuiles
   mutuellement en conflit forment trois paires, mais faire sortir deux tuiles
   suffit — `+6` surestimerait. D'où le retrait glouton, qui compte le nombre
   minimal de tuiles à sortir. Vérifié par les deux cas d'école de
   `tests/test_heuristic.c`.
3. **Jeter un fils déjà connu sans comparer `g`.** Faux en général : un état
   présent sur l'open list n'a pas forcément son `g` optimal, et le jeter fige
   le plus long des deux chemins. Ça ne casse pas systématiquement ici parce
   que la parité du graphe force les deux chemins à différer d'au moins 2, ce
   qui exige une égalité exacte de `f` — mais ça arrive. Chiffre : voir
   `results/dup-policy.csv`, colonnes `solution_len` contre `optimal`.
4. **`onList` avant et après.** Avant : `O(n)`, un `memcmp` par nœud, appelé
